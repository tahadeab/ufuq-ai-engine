# Python Data Structures

This practical guide introduces the core data structures used in Python programming.

## Lists and Tuples

Lists are ordered, mutable collections. Tuples are ordered collections that cannot be changed after creation.

## Dictionaries

Dictionaries store key-value pairs and provide fast lookup by key.

## Learning Objectives

By the end, learners can choose a suitable data structure and explain its trade-offs.

## Practical Exercise

Compare a list, tuple, and dictionary for storing learner records.
